# Privacy Policy

_Last updated: 15 November 2026_

Personal Agent is a private, single-user command-line tool. It is used only by
its owner, on the owner's own computer, to work with the owner's own Google
Drive account.

## What the app accesses

After the owner signs in with Google, the app uses the Google Drive API to list,
search, download and upload files in the owner's Drive. It requests the Google
Drive scope (`https://www.googleapis.com/auth/drive`) only for this purpose.

## What is stored

The only data the app stores is the OAuth sign-in token that Google issues. It
stays in a private file on the owner's own computer. Files that the owner
downloads are saved on that computer at the owner's request.

## What is shared

Nothing. The app does not send Google user data to any server of its own, to the
developer or to any third party. It has no analytics, no advertising and no
tracking. Data is not used to train AI or machine-learning models.

## Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Revoking access and deleting data

The owner can revoke the app's access at any time at
<https://myaccount.google.com/permissions>. Deleting the local token file also
removes the stored sign-in.

## Contact

Questions about this policy can be raised as an issue in this repository.
