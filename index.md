# Personal Agent

Personal Agent is a private, single-user command-line tool. It runs only on its
owner's own computer and lets the owner list, search, download and upload files
in their own Google Drive account using the Google Drive API.

It is not a public service, has no other users and does not collect or share
data. Read the [privacy policy](privacy/).

Questions can be raised as an issue in this repository.
